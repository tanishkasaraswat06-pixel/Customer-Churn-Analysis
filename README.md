# Customer Churn Analysis

## Project Overview
Customer Churn Analysis is a Python-based data analytics project that analyzes customer subscription data to identify patterns and factors associated with customer cancellations.

The project explores customer behaviour, contract types, tenure, monthly charges, payment methods, and internet services to understand customer churn.

## Objectives
- Analyze customer churn patterns.
- Identify factors associated with customer cancellations.
- Perform data cleaning and exploratory data analysis.
- Create visualizations to understand customer behaviour.
- Suggest strategies to improve customer retention.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- VS Code

## Dataset
IBM Telco Customer Churn Dataset:
- 7,043 customer records
- 21 columns

## Key Findings
- Overall customer churn rate: 26.54%.
- Month-to-month contracts have a churn rate of 42.71%.
- One-year contracts have a churn rate of 11.27%.
- Two-year contracts have a churn rate of 2.83%.
- Electronic check users have the highest churn count.
- Fiber optic customers have the highest churn count by internet service.

## Business Recommendations
1. Offer retention discounts to month-to-month customers.
2. Improve customer support during the early subscription period.
3. Review pricing plans for high-paying customers.
4. Encourage automatic payment methods.
5. Develop targeted customer retention strategies.
